## Описание программы
Expense Tracker — это десктопное приложение для отслеживания личных финансов. Программа позволяет вести учёт расходов, фильтровать записи по категориям и датам, а также автоматически подсчитывать сумму за выбранный период.

### Возможности:
- Добавление расходов с указанием суммы, категории и даты
- Автоматическая валидация ввода (положительная сумма, корректный формат даты)
- Фильтрация расходов по категории и временному периоду
- Подсчёт общей суммы расходов и статистика по категориям
- Сохранение и загрузка данных в формате JSON
- Удобный табличный интерфейс с возможностью удаления записей
- Контекстное меню для быстрого удаления

## Как использовать
Инструкция по использованию
Добавление расхода
Введите сумму в поле "Сумма" (только положительные числа)

Выберите категорию из выпадающего списка

Укажите дату в формате ГГГГ-ММ-ДД (по умолчанию подставляется текущая дата)

Нажмите кнопку "Добавить расход"

Фильтрация
По категории: выберите нужную категорию из списка

По дате: укажите начальную и/или конечную дату периода

Нажмите "Применить фильтр" для обновления списка

Кнопка "Сбросить" очищает все фильтры

Удаление записей
Через контекстное меню: кликните правой кнопкой мыши на записи и выберите "Удалить запись"

Вы также можете выделить запись и использовать сочетание клавиш (если добавите)

Просмотр статистики
В нижней части окна отображается общая сумма расходов за отфильтрованный период

Также показана разбивка по категориям
